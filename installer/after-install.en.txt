Sesli Okuma is installed.

HOW TO USE
  - Select text in any program and press Ctrl + Alt + S - it is read aloud.
  - Press Ctrl + Alt + S again while reading - it stops.
  - Click the speech-bubble icon in the taskbar tray (hidden icons area) to open the settings panel:
    interface language, shortcut, voices per language, speed, start with Windows.

NATURAL VOICES (OPTIONAL)
  Windows' built-in voices sound robotic. The settings panel offers a one-click installation of the free,
  open-source NaturalVoiceSAPIAdapter, which adds Microsoft's online neural voices for many languages
  (internet required). It is an independent project - https://github.com/gexgd0419/NaturalVoiceSAPIAdapter

PRIVACY
  Sesli Okuma collects and sends no data. Text is passed only to the voice provider you choose (Windows SAPI).
